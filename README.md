# GTA_Lite - A Simple GTA-like Game in Python

## 🔧 Requirements
- Python 3.x
- Pygame

## 📥 Installation
```sh
pip install -r requirements.txt

```
🚀 Run the Game
```sh
python game.py
```

🎮 Controls
WASD - Move Player
SPACE - Shoot Bullet

📦 Assets
Sprites from Kenney.nl
Sounds from Freesound.org


---

## ✅ **Final Steps**
1. **Download assets** from links in previous messages.
2. **Organize them in `assets/` folder**.
3. **Run the game:**
   ```sh
   python game.py
   ```
   
🎮 Enjoy!
